# PDFeditz browser extension

The extension provides a lightweight entry point into PDFeditz from the browser toolbar.

## Development

1. Open the browser's extension management page.
2. Enable developer mode.
3. Load the `extension/` directory as an unpacked extension.
4. Open the toolbar popup and select a PDFeditz action.

The extension does not replace the main application. PDF processing remains in the PDFeditz web application and follows its local-first behavior.
